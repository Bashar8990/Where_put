Prevent pinch-zoom and double-tap zoom for native app feel

- Add maximum-scale=1, user-scalable=no to viewport meta
- Set touch-action: pan-x pan-y on body to block zoom gestures
- Prevent iOS gesturestart/gesturechange/gestureend events
- Prevent double-tap zoom via touchend timing check
- Set input font-size to 16px to prevent iOS auto-zoom on focus
