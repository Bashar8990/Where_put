Fix CI/CD and build: run lint+tests in CI, derive base from repo, add maskable icon, apple-touch-icon, relative favicon

Five issues fixed:

1. CI did not run lint or tests before deploying — broken tests/lint could
   be deployed to GitHub Pages. Added npm run lint and npm run test steps
   before the build step in deploy.yml.

2. base path was hard-coded to '/Where_put/' — renaming the repo would
   break deployment. Now derived from GITHUB_REPOSITORY env var (set
   automatically by GitHub Actions), with BASE_PATH fallback for custom
   hosting.

3. includeAssets was missing icons/icon-maskable-512.png, which is
   referenced in the manifest but not pre-cached by the service worker.
   Now included.

4. index.html had no Apple Touch Icon — iOS "Add to Home Screen" used a
   generic screenshot. Added <link rel="apple-touch-icon"> pointing to
   icon-192.png.

5. favicon.svg used an absolute path (/favicon.svg) which Vite may not
   rewrite under a non-root base. Changed to relative (favicon.svg) so it
   works correctly under /Where_put/ on GitHub Pages.
