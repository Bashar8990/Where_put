Fix memory leaks and races: delete dead useLiveQuery, fix object URL revoke, clean up timers

Five issues fixed:

1. Deleted unused useLiveQuery hook (dead code, not used anywhere).

2. Object URL revoke race in ItemImage and ImagePicker: the cleanup was
   revoking the previous URL before the new image finished loading, causing
   a brief broken-image flicker. Now the previous URL is revoked only after
   the new one is committed to state via a ref.

3. setInterval leak in PWAUpdatePrompt: the SW update interval was never
   saved or cleared, causing accumulation on re-register and a leak on
   unmount. Now tracked via useRef and cleared on unmount.

4. setTimeout for purge not cleared in HomePage, ItemDetailsPage, and
   FavoritesPage: could fire after unmount. Now tracked via useRef and
   cleared on unmount.

5. Touch listeners in main.tsx: already removed by a prior commit
   (gesturestart/change/end and touchend handlers are gone).
